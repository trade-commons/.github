# .github

Organisation-wide defaults for the `trade-commons` GitHub organisation.

| Path | What it does |
|---|---|
| `profile/README.md` | The text shown on <https://github.com/trade-commons> |
| `CONTRIBUTING.md` | Default contribution guide for every repository without its own |
| `CODE_OF_CONDUCT.md` | Default code of conduct |
| `SECURITY.md` | Default vulnerability reporting policy |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template |

A repository that needs different text carries its own copy, which overrides the default here.

This repository must be public for GitHub to serve the organisation profile.
